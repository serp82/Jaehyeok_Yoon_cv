# Semantic attribute examples

SAVOR composes one structural description with one spectral description for each known waveform class. The examples below are the source table's sampled descriptions.

| Waveform | Structural pattern candidates | Spectral characteristic candidates | Sampled description example |
| --- | --- | --- | --- |
| LFMU | ascending straight diagonal line; positively sloped linear trace; straight ramp going upwards from left to right | continuous and smooth energy distribution; solid, unbroken main energy ridge; clear linear sweep without discrete steps | *A positively sloped linear trace showing a solid, unbroken main energy ridge.* |
| Barker | horizontal central thick line interrupted by vertical spikes; single horizontal band with sharp vertical striations; barcode-like pattern of vertical flashes along a horizontal axis | abrupt broadband vertical artifacts due to phase flips; momentary wideband energy bursts; transient wide vertical spreads | *A barcode-like pattern of vertical flashes along a horizontal axis, showing abrupt broadband vertical artifacts due to phase flips.* |

Source: `thesis/chapters/05_open_set_recognition/tables/semantic_attribute_examples.tex`.
