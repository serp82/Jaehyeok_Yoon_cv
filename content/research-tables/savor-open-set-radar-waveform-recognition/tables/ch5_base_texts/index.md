# Attribute-aware base-text templates

Generic time-frequency pattern descriptors are sampled and inserted into descriptive templates to create semantic directions that are not tied to a specific known waveform class.

| Generic pattern pool | Template pool | Constructed base text examples |
| --- | --- | --- |
| vertical streak; horizontal band; diffuse blob; fragmented trace; broad smear; localized spot; faint ridge; scattered energy; textured patch; irregular cluster | “{p}”; “a radar spectrogram showing {p}”; “a time-frequency plot with {p}”; “a noisy spectrogram with {p}” | “a radar spectrogram showing vertical streak”; “a noisy spectrogram with diffuse blob”; “a time-frequency plot with scattered energy” |
